# Android: уведомления чатов

Клиент использует Firebase Cloud Messaging. Серверная функция `notifyChatMessage` отправляет уведомления при создании обычного сообщения в `chats/{chatId}/messages/{messageId}`. Редактирование и служебные события не уведомляют. Токены лежат в `users/{uid}/devices/{deviceId}`, доступны только владельцу и Admin SDK. Просроченные токены удаляются после отказа FCM. Удаление аккаунта удаляет зарегистрированные устройства.

## Публикация

Нужны тариф Blaze и вход Firebase CLI в проект `zero-91cc8`. Сначала выполнить локальные проверки, затем:

```powershell
node tool/sync_push_strings.cjs
firebase deploy --only firestore:rules,functions:notifyChatMessage --project zero-91cc8
```

`firebase.json` также обновляет серверные строки из `lib/l10n/app_ru.arb` перед публикацией. Сервер использует Node.js 22, регион `europe-west1`, ноль постоянно работающих экземпляров и максимум два экземпляра. Эти настройки не являются денежным лимитом. В Firebase/Google Cloud следует настроить бюджет и доступный лимит расходов функции; обычные бюджетные оповещения не блокируют списания.

Android-сборка читает `firebase/google-services.json` и создаёт нативные ресурсы Firebase: они нужны для получения push после завершения процесса, ещё до запуска Dart. Этот файл не публикуется в git. Локальная конфигурация должна соответствовать `lib/firebase_options.dart`.

## Проверка на телефоне

1. Установить APK поверх предыдущего. Открыть приложение с созданным профилем друзей и разрешить уведомления Android.
2. Отправить сообщение со второго аккаунта в личный и групповой чат: проверить уведомление при свёрнутом и закрытом приложении, открытие нужного чата по нажатию, а также изображение без подписи.
3. В открытом чате не должно быть отдельного уведомления о его новом сообщении. Изменение сообщения и собственные сообщения не должны создавать уведомлений.
4. Запретить уведомления в настройках Android: они перестают показываться. После разрешения открыть приложение снова.

Нужны Google Play Services. После системной команды «Остановить принудительно» Android блокирует доставку до следующего открытия приложения. Доставку в реальном фоне нельзя подтвердить одной компиляцией или тестами правил.

## Локальные проверки правил

В `functions/` установлены зависимости для тестов (`pnpm install`). Запуск из корня:

```powershell
firebase emulators:exec --only firestore --project demo-zero "node --test functions/test/firestore.test.cjs"
```

Используется отдельный демонстрационный проект и порт 8087, реальные данные не меняются.

iOS: push не включён; автоматическая регистрация Messaging отключена в Info.plist. Для запуска позже нужны Apple Developer, APNs-ключ в Firebase и возможности Push Notifications / Remote notifications в Xcode.

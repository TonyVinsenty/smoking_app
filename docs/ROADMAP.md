# Zero — план, решения и прогресс

Обновляется по мере работы. Правила работы и технические заметки — в `CLAUDE.md`, копилка идей контента — в `docs/content-ideas.md`.

## Цель

Доброе приложение-помощник для отказа от курения (сигареты, стики IQOS, вейпы) для Android и iOS. Сначала — для владельца (тест на его Android и iPhone), потом — публикация в магазинах. Прогресс должен ощущаться щедро и наглядно, без упрёков и стыда. Приложение полностью бесплатное (решение владельца 2026-10-13): без подписок и платных функций; в Настройках — добровольная кнопка «Помочь автору».

## Решения по продукту

- **Вкладки:** Главная · Здоровье · Знания · Рейтинг · Настройки.
- **Онбординг:** что курит пользователь (сигареты / стики для нагревания / одноразовый вейп / жидкость для многоразового — можно несколько), расход в день/неделю/месяц, цена за единицу (пачка / пачка стиков / одноразка / флакон жидкости), дата отказа (может быть в прошлом; время «Не помню» = 10:00). Нужно для подсчёта сэкономленных денег.
- **Главная:** таймер без курения, уровень + полоса опыта (XP), сэкономленные деньги, невыкуренные единицы, мотивирующая цитата.
- **SOS «Хочу курить»:** плавающая кнопка на каждом экране (+ позже виджет на рабочем столе). Сценарий: один тап «что происходит» (повод → карта тяги) → упражнение + быстрые советы → «Тяга прошла!» (записывается, даёт XP). Карта тяги показывает личные закономерности (время суток / повод).
- **Здоровье:** этапы восстановления организма. Медицинский дисклеймер обязателен.
- **Уровни и достижения:** XP = 1 за каждый час без курения (копится по всем попыткам, никогда не теряется) + 10 за преодолённую тягу + XP за достижения. Прогресс щедрый: 50 уровней (в первую неделю повышение ~раз в день, после года ~раз в месяц, 50-й ≈ 3,4 года), 97 достижений с редкостью как в WoW (обычный…легендарный). Значки за время — в рамках попытки, остальные — накопительно.
- **Тон текстов:** на «вы», гендерно-нейтрально, никогда не стыдить («Я закурил(а)», «Тяга прошла!»).
- **«Я закурил(а)»:** только в Настройках. Одно подтверждение от случайного нажатия, затем «дневник без упрёков»: повод (стресс, алкоголь, компания, кофе, после еды, скука, привычный момент, другое) + 3 необязательных вопроса (что случилось / что бы помогло / что попробую в следующий раз). Завершает попытку; значки остаются в истории; рекорд сохраняется.
- **Празднование:** анимация нового значка при 1–3 открытиях «вживую»; пачка открытий задним числом — просто всплывающее сообщение. Владелец хочет больше плавности и анимаций.
- **Уведомления:** редкие, только поддерживающие, никогда не надоедливые.
- **Доступность:** тёмная тема; размер шрифта следует системной настройке телефона (своей опции нет).
- **Статистика и факты:** только реальные цифры из исследований с источниками, ничего не выдумывать (медицинская тема, доверие).
- **Без премиума (решение 2026-10-13):** всё бесплатно. «Помочь автору» — ссылка на добровольный донат в Настройках. Перед публикацией в магазинах проверить правила: Google Play и App Store не разрешают донаты частному лицу по внешней ссылке (нужны встроенные покупки-«чаевые» или кнопку убрать в магазинной сборке).
- **Стиль:** спокойный, «здоровый» (зелёный/бирюзовый), светлая и тёмная темы. Шрифт чисел и заголовков — Manrope, текст — Roboto. Тёплый абрикосовый акцент — только для наград и праздников. Движение короткое (0,2–0,6 с), мягкое и всегда со смыслом; яркие эффекты — только для редких побед.

## Фазы

1. **MVP без интернета** (сейчас): каркас → онбординг → главная/деньги/уровни → здоровье/достижения → SOS → срыв + поводы + история → база знаний → уведомления → настройки → тест на устройствах → правки по отзывам.
2. **Полировка:** анимации, статистика карты тяги, больше статей, иконка; советы SOS и статьи под тип продукта (вейп/IQOS); виджет на рабочем столе (таймер/деньги) + карточки этапов, которыми можно поделиться; лёгкие еженедельные челленджи (+XP); витрина значков («полка»); тест «какой я курильщик» в онбординге; честная серия статей про вейпы/IQOS; анонимные истории пользователей.
3. **Сообщество и выпуск:** рейтинг и друзья (код друга) на бесплатном тарифе Firebase/Supabase; анонимные добровольные «эстафеты»; «второй пилот» (по желанию близкий человек получает добрые уведомления); публикация в магазинах (кнопку «Помочь автору» привести к правилам магазинов).

## Сделано (фаза 1)

- **Каркас и онбординг:** название Zero, вкладки, онбординг с продуктами, расходом, ценами и датой отказа.
- **Главная:** календарный таймер (годы/месяцы/недели/дни + часы + всего дней, разделители), экономия с пояснением ⓘ «Как считаем» и окном «Подробнее» (сегодня / неделя / месяц / всего + прогноз), невыкуренные единицы, уровень/XP, цитата (тап — следующая), карточка «Карта тяги», кнопка «Достижения» вверху (заголовка «Zero» нет), цитата постоянной высоты.
- **SOS:** выбор повода → 3 упражнения (спокойное дыхание 4/6 без задержки, отсчёт 10→0, заземление 5-4-3-2-1; выбор в SOS и в Настройках, запоминается; заметная кнопка «Сменить»; рамка заземления постоянного размера), советы на «вы», «Тяга прошла!»; кнопка SOS полупрозрачная.
- **Карта тяги:** период 7д/30д/всё, сводка, время суток + пиковый час, поводы, совет для главного повода, дни недели; столбцы «справились/закурили».
- **Здоровье:** вкладки сверху «Этапы · Факты · Что сейчас нормально · Карта тела · Не попало в организм · Дневник» (без заголовка экрана). «Этапы» — «Тропа» — извилистая дорожка этапов с отметкой «Вы здесь» (пройденное сплошной линией, впереди пунктир, следующий этап пульсирует), фильтры «Пройденные · Ближайшие · Все» (при «Все» прокрутка к «Вы здесь»), сводка «Пройдено N из 20» + следующий этап + заметка про первые 8 дней, «Факты из исследований» (health_facts.json: Hughes 2004, Chaiton 2016, Jha 2013), дисклеймер.
- **Достижения:** отдельный экран с главной (кнопка «Достижения»), группы свёрнуты по умолчанию (запоминается), «Свернуть все / Развернуть все», «N из M (P%)».
- **Достижения и уровни:** 97 значков, значки за единицы по главному продукту, уровни подобраны симуляцией.
- **Срыв и история:** «Я закурил(а)» → дневник без упрёков → «Начать новую попытку сейчас / Начну позже»; «История попыток» (рекорд, всего, значки по попыткам, повод, дневник); привычки хранятся по попыткам (новая попытка: «Оставить / Изменить»).
- **Знания:** 37 статей, темы свёрнуты по умолчанию (запоминается) (в т.ч. «Помощь и лечение»), фильтр по темам, при «Все» — группы по темам с заголовками и счётчиком, отдельные карточки с иконкой темы, «Прочитано X из N», статья читается при прокрутке до конца, «Следующая статья», дисклеймер.
- **Уведомления:** этапы здоровья от 1 дня, тихие часы 21–10, переключатель «Этапы восстановления»; напоминание о Дневнике самочувствия (галочка, частота, время; красные точки на «Здоровье» и «Дневнике»), разрешение спрашивается при первом открытии главной.
- **Настройки:** «Цветовой тон» (Системный · Тёмный · Светлый), упражнение SOS по умолчанию, «Моя попытка», «Мои привычки», «Полный сброс».
- **Выпуск:** версия 0.1.0; подписанный APK и iOS-сборка через GitHub Actions + Sideloadly. Сборки 1 и 2 установлены на Android и iPhone владельца; сборки 3 (раунд 2) и 4 (раунд 3) собраны.

## Отзывы владельца

### Раунд 1 (2026-10-12) — закрыт, сборка 0.1.0+2, одобрено
Ребаланс XP и достижений (97 значков, редкость, группы, значки по главному продукту, нейтральные тексты); барабан выбора времени (как будильник iPhone); кнопка «Сменить» в SOS; рамка заземления постоянного размера; убран «Крупный текст», приложение подстраивается под системный шрифт (проверено при ×2); кубок на главной → Достижения (иконка «Рейтинга» — пьедестал); новые карточки и группы в «Знаниях».

### Раунд 2 (2026-10-12) — закрыт, сборка 0.1.0+3, одобрено

- [x] **g) Новая вкладка «Здоровье»** (с агентом-дизайнером; сначала показать владельцу 2–3 варианта и дождаться выбора). Разделы вместо «Восстановление/Достижения»: этапы восстановления с фильтрами «пройденные / ближайшие / все» и наглядной отметкой «Вы здесь» (лента/путь, не сухой график); мотивирующая статистика (например, на каких этапах чаще срываются — только реальные данные с источниками); возможно что-то ещё. Радостнее, меньше сухости.

- [x] **g) Дневник самочувствия** (владелец тестирует несколько дней, потом, возможно, уберём): опросник по шкале — сон, дыхание, настроение, вкус и запах; график «как становится лучше». Пока напоминания включены и пора заполнять: красная точка на вкладке «Здоровье» и на подразделе «Дневник». Если галочка выключена — точек нет.

- [x] f) Крупный шрифт: надписи переносятся только целыми словами и одного размера, сегменты при нехватке места — столбиком, мягкие переносы в длинных словах («Кровообра­щение»), «Вечер» не обрезается, иконки растут со шрифтом (до разумного предела), на главной «XP» не налезает на название уровня, дата под таймером по центру.

**Экраны**
- [x] g) Кнопка SOS: плотная (не полупрозрачная), при прокрутке вниз сворачивается в кружок, вверх — снова «SOS»; во всех списках снизу пустое место ~96 dp.
- [x] h) Главная: мягкое затухание сверху под кнопкой «Достижения · 43»; белые карточки; под таймером прогресс до следующего этапа; уровень в кольце прогресса; «15 757 XP»; нажимается вся половина «Сэкономлено» (не только «Подробнее»).
- [x] i) Экран SOS: рамка совета растёт по тексту (но не меньше нужной высоты — круг не прыгает); название упражнения слева, «Сменить» справа; «Тяга прошла!» — с галочкой, кнопка повыше.
- [x] j) Значки: медаль с ободком цвета редкости (цвета смягчены к бирюзе, без неона, легендарные — тёплый «золотой»), подписи обычным цветом текста; закрытые — контур + кольцо прогресса «18 из 200 дней»; в карточке нового значка кнопка «Забрать» (как у Flamy).
- [x] k) Карта тела: плитка светлая, прогресс — точки (●●○○○); все этапы пройдены — мятная с галочкой.
- [x] l) Дневник: четыре маленьких графика (по одному на вопрос) со шкалой 1–5 и «было → стало», цвета из палитры; при <2 записях — подсказка вместо графика.
- [x] m) История попыток: метки плоские; текущая попытка — обычная карточка с бирюзовой обводкой и надписью «Сейчас»; «Всего без курения» → «Всего».
- [x] n) Настройки: группы-карточки; везде переключатели (вместо галочки у Дневника); отступы по одной линии; иконки напротив первой строки; «Цветовой тон» → «Тема оформления», в конце, раздел «Оформление».
- [x] o) «Рейтинг»: нормальное пустое состояние (картинка + «Здесь будет рейтинг с друзьями… Всё анонимно и по желанию» + «Появится в одном из следующих обновлений»). Вкладку не прячем.
- [x] p) Числа: проценты округлять обычным образом, 100% — только когда открыто всё.
- [x] q) Мои привычки: содержимое прижать к верху; «Штук в пачке» → «В пачке, шт.»; кнопки «в день / в неделю / в месяц» на всю ширину.
- [x] r) Короткая подсказка при первом открытии Карты тяги и Дневника (из «Взять»).

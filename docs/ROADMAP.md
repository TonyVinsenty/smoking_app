# Zero — план, решения и прогресс

Обновляется по мере работы. Правила работы и технические заметки — в `CLAUDE.md`, копилка идей контента — в `docs/content-ideas.md`.

## Цель

Доброе приложение-помощник для отказа от курения (сигареты, стики IQOS, вейпы) для Android и iOS. Сначала — для владельца (тест на его Android и iPhone), потом — публикация в магазинах. Прогресс должен ощущаться щедро и наглядно, без упрёков и стыда. Все основные функции бесплатны; позже — премиум-подписка с приятными дополнениями.

## Решения по продукту

- **Вкладки:** Главная · Здоровье · Знания · Рейтинг · Настройки.
- **Онбординг:** что курит пользователь (сигареты / стики для нагревания / одноразовый вейп / жидкость для многоразового — можно несколько), расход в день/неделю/месяц, цена за единицу (пачка / пачка стиков / одноразка / флакон жидкости), дата отказа (может быть в прошлом; время «Не помню» = 10:00). Нужно для подсчёта сэкономленных денег.
- **Главная:** таймер без курения, уровень + полоса опыта (XP), сэкономленные деньги, невыкуренные единицы, мотивирующая цитата.
- **SOS «Хочу курить»:** плавающая кнопка на каждом экране (+ позже виджет на рабочем столе). Сценарий: один тап «что происходит» (повод → карта тяги) → упражнение + быстрые советы → «Тяга прошла!» (записывается, даёт XP). Карта тяги показывает личные закономерности (время суток / повод).
- **Здоровье:** этапы восстановления организма. Медицинский дисклеймер обязателен.
- **Уровни и достижения:** XP = 1 за каждый час без курения (копится по всем попыткам, никогда не теряется) + 10 за преодолённую тягу + XP за достижения. Прогресс щедрый: 50 уровней (в первую неделю повышение ~раз в день, после года ~раз в месяц, 50-й ≈ 3,4 года), 97 достижений с редкостью как в WoW (обычный…легендарный). Значки за время — в рамках попытки, остальные — накопительно.
- **Тон текстов:** на «вы», гендерно-нейтрально, никогда не стыдить («Я закурил(а)», «Тяга прошла!»).
- **«Я закурил(а)»:** только в Настройках. Одно подтверждение от случайного нажатия, затем «дневник без упрёков»: повод (стресс, алкоголь, компания, кофе, после еды, скука, привычный момент, другое) + 3 необязательных вопроса (что случилось / что бы помогло / что попробую в следующий раз). Завершает попытку; значки остаются в истории; рекорд сохраняется.
- **Празднование:** анимация нового значка при 1–3 открытиях «вживую»; пачка открытий задним числом — просто всплывающее сообщение. Владелец хочет больше плавности и анимаций.
- **Уведомления:** редкие, только поддерживающие, никогда не надоедливые.
- **Доступность:** тёмная тема; размер шрифта следует системной настройке телефона (своей опции нет).
- **Статистика и факты:** только реальные цифры из исследований с источниками, ничего не выдумывать (медицинская тема, доверие).
- **Премиум (позже, ближе к релизу):** основные функции бесплатны; премиум = темы, особый значок в рейтинге, особое достижение, дополнительные приятные функции.
- **Стиль:** спокойный, «здоровый» (зелёный/бирюзовый), светлая и тёмная темы.

## Фазы

1. **MVP без интернета** (сейчас): каркас → онбординг → главная/деньги/уровни → здоровье/достижения → SOS → срыв + поводы + история → база знаний → уведомления → настройки → тест на устройствах → правки по отзывам.
2. **Полировка:** анимации, статистика карты тяги, больше статей, иконка; советы SOS и статьи под тип продукта (вейп/IQOS); виджет на рабочем столе (таймер/деньги) + карточки этапов, которыми можно поделиться; лёгкие еженедельные челленджи (+XP); витрина значков («полка»); тест «какой я курильщик» в онбординге; честная серия статей про вейпы/IQOS; анонимные истории пользователей.
3. **Сообщество и выпуск:** рейтинг и друзья (код друга) на бесплатном тарифе Firebase/Supabase; анонимные добровольные «эстафеты»; «второй пилот» (по желанию близкий человек получает добрые уведомления); затем премиум (темы, наборы иконок, рамки значков, премиум-значок, расширенная статистика/экспорт, шаблоны карточек); публикация в магазинах.

## Сделано (фаза 1)

- **Каркас и онбординг:** название Zero, вкладки, онбординг с продуктами, расходом, ценами и датой отказа.
- **Главная:** календарный таймер (годы/месяцы/недели/дни + часы + всего дней, разделители), экономия с пояснением ⓘ «Как считаем» и окном «Подробнее» (сегодня / неделя / месяц / всего + прогноз), невыкуренные единицы, уровень/XP, цитата (тап — следующая), карточка «Карта тяги», кнопка «Достижения» вверху (заголовка «Zero» нет), цитата постоянной высоты.
- **SOS:** выбор повода → 3 упражнения (спокойное дыхание 4/6 без задержки, отсчёт 10→0, заземление 5-4-3-2-1; выбор в SOS и в Настройках, запоминается; заметная кнопка «Сменить»; рамка заземления постоянного размера), советы на «вы», «Тяга прошла!»; кнопка SOS полупрозрачная.
- **Карта тяги:** период 7д/30д/всё, сводка, время суток + пиковый час, поводы, совет для главного повода, дни недели; столбцы «справились/закурили».
- **Здоровье:** «Тропа» — извилистая дорожка этапов с отметкой «Вы здесь» (пройденное сплошной линией, впереди пунктир, следующий этап пульсирует), фильтры «Пройденные · Ближайшие · Все» (при «Все» прокрутка к «Вы здесь»), сводка «Пройдено N из 20» + следующий этап + заметка про первые 8 дней, «Факты из исследований» (health_facts.json: Hughes 2004, Chaiton 2016, Jha 2013), дисклеймер.
- **Достижения:** отдельный экран с главной (кнопка «Достижения»), группы сворачиваются, «N из M (P%)».
- **Достижения и уровни:** 97 значков, значки за единицы по главному продукту, уровни подобраны симуляцией.
- **Срыв и история:** «Я закурил(а)» → дневник без упрёков → «Начать новую попытку сейчас / Начну позже»; «История попыток» (рекорд, всего, значки по попыткам, повод, дневник); привычки хранятся по попыткам (новая попытка: «Оставить / Изменить»).
- **Знания:** 25 статей (в т.ч. «Помощь и лечение»), фильтр по темам, при «Все» — группы по темам с заголовками и счётчиком, отдельные карточки с иконкой темы, «Прочитано X из N», статья читается при прокрутке до конца, «Следующая статья», дисклеймер.
- **Уведомления:** этапы здоровья от 1 дня, тихие часы 21–10, переключатель «Этапы восстановления», разрешение спрашивается при первом открытии главной.
- **Настройки:** «Цветовой тон» (Системный · Тёмный · Светлый), упражнение SOS по умолчанию, «Моя попытка», «Мои привычки», «Полный сброс».
- **Выпуск:** версия 0.1.0; подписанный APK и iOS-сборка через GitHub Actions + Sideloadly. Сборки 1 и 2 установлены на Android и iPhone владельца; сборка 3 (раунд 2) собрана.
